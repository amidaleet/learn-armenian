# Learn Armenian

Личный репозиторий для бытового **восточного** армянского с нуля: история, база и простые HTML-игры. Русский и английский — рабочие языки якорей. Цель — магазин, кафе, такси, знакомство, простой рассказ о себе. Не литературный перевод и не западный вариант.

Транслит в карточки не кладём. Алфавит фонетический: как только буквы звучат, чтение почти бесплатное.

## Как учить

Каждый день одна петля на 30–45 минут. Инструменты не заменяют её.

1. **Recall** — сказать или напечатать, не только кликнуть.
2. **Интервалы** — повторять почти забытое, не уже лёгкое.
3. **Вход** — слушать и читать чуть выше своего уровня.
4. **Выход** — 2–5 своих фраз вслух, даже кривых.

Кликовые квизы — для алфавита. Для слов и фраз печатный ответ сильнее.

Порядок такой:

1. Алфавит до автоматизма (1–2 недели): звук, рукопись, чтение вслух. Пары `թ/տ`, `փ/պ`, `ք/կ`, `չ/ճ`, `ց/ծ`, `ղ/խ`, `ե/է`, `ո/օ`, `ր/ռ`.
2. Бытовые куски, не словари: приветствие, «хочу», «где», «сколько стоит», «не понимаю».
3. Частотные слова и короткий вход (субтитры, детские ролики, меню).
4. Грамматику добывать из повторяющихся окончаний в живых фразах, не из полных таблиц заранее.

Русский помогает с падежным мышлением и советскими заимствованиями; калек вроде «я иду» → дословный порядок ждать не стоит. Раскладку восточноармянскую поставить сразу и печатать в играх.

## Структура

Данные — главный актив. Игры — тонкий клиент над JSON.

```text
data/                 колоды
  alphabet.json       39 графем: буква, звук, пример
  audio/              озвучка букв и слов-примеров
  phrases.json        бытовые куски
  words.json          частотные якоря
games/                HTML без сборки
  alphabet/           буква → звук
notes/                короткие наблюдения, не конспекты
log/                  дневник занятий
  TEMPLATE.md
script/               python-логика задач Xfile
  journal.py
  serve.py
Xfile                 задачи репо (`x serve`, `x session`)
Xfile_source/         движок оркестратора
```

Схемы намеренно плоские, чтобы колоду было легко править руками и подключать к новой игре.

**Буква** (`data/alphabet.json`): `id`, `upper`, `lower`, `name_hy`, `ipa`, `ru_approx`, `example`, по необходимости `notes`.

**Фраза / слово**: `id`, `hy`, `ru`, `en`, `tags`, по необходимости `notes`. Смысловой якорь — `ru`. Поле `en` — запасной пояснительный слой, не то, что учим.

В `notes/` один файл — одна тема (`ech-vs-e.md`, `aspiration.md`). Старт занятия:

```bash
./Xfile session
./Xfile session --focus алфавит
```

Пишет блок в `log/YYYY-MM-DD.md`. После раунда алфавита игра сама дописывает строку `Раунд` (счёт и минуты), если открыта через `./Xfile serve`. Фразы вслух — руками.

## План

| Фаза | Фокус | Готово, когда |
| --- | --- | --- |
| 1. Алфавит | Узнавание, звук, печать, пары | Видишь букву — слышишь звук без таблицы |
| 2. Выживание | 80–150 фраз из `phrases.json` | Магазин, приветствие, «не понимаю», «хочу» |
| 3. Частотность | 600–800 слов + клозе в предложениях | Читаешь вывеску и простое меню с догадкой |
| 4. Быт | Вход каждый день, короткий выход | Разговор о еде, дороге, себе в 4–8 фраз |

Игры по мере надобности, не заранее: алфавит (есть) → печать слова → SRS/клозе → сборка фразы → аудио. Не делать движок два месяца до первой буквы.

Бытовой уровень при ежедневной петле часто 4–8 месяцев. Метрика — минуты входа и фразы вслух, не число файлов в репо.

## Запуск игр

Из корня репо:

```bash
./Xfile serve
```

Если настроен alias `x` (см. `Xfile_source/completion.sh`):

```bash
x serve
```

Другой порт: `./Xfile serve --port 9000`. Дальше [http://127.0.0.1:8000/games/](http://127.0.0.1:8000/games/). `file://` не подхватит JSON и не запишет раунд в журнал.

Список задач: `./Xfile help`.

## Не делать

- учить слова в транслите
- смешивать восточный и западный
- копить только узнавание (четыре кнопки) после алфавита
- откладывать говорение «пока не будет грамматики»
- идеальную систему прогресса вместо дневной петли
